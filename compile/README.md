## Возможности

- До семи вкладок: закрепление, перетаскивание, иконки сайтов, индикатор звука и новая вкладка.
- Компактная адресная строка: `https://` скрывается только визуально, полный адрес сохраняется при копировании.
- До четырёх изолированных профилей. Переключение профиля во всех вкладках включено по умолчанию.
- Детектор аномалий с журналом, звуком, тостами и отображением оставшегося количества наград.
- Автоподписка сравнивает подписчиков и подписки, выполняет не более пяти действий за проверку и запускается не чаще одного раза в 10 минут.
- Белый и чёрный списки хранятся отдельно для каждого профиля. Чёрный список только игнорирует заявки.
- Пользовательские функции: до девяти JavaScript-файлов `.js`, с отдельным переключателем, перестановкой перетаскиванием и поиском через `Ctrl+K`.
- Секретки с синхронизацией достижений, поиском, инструкциями и секреткой `IDKFA`.
- Быстрая очистка дискового кэша страниц без сброса авторизации и сессий.
- Контекстное меню встроенной страницы: копирование, вставка и обновление.

Детектор и автоподписка доступны только после авторизации выбранного профиля. При смене профиля и закрытии приложения функции выключаются, а журнал очищается.

## Установка

1. Скачайте **AnimeOn Desktop.exe** из [Releases](https://github.com/Kotecy/Animeon-Desktop/releases).
2. Запустите файл — установка не требуется (portable).
3. Войдите в AnimeOn и включите нужные функции.

Локальные данные находятся в `%LOCALAPPDATA%\AnimeonDesktop`. Логи вынесены в подкаталог `%LOCALAPPDATA%\AnimeonDesktop\logs`.

Вход через Google во встроенном браузере может быть отклонён самим Google. В этом случае используйте любой другой доступный способ авторизации на сайте.

## Управление

| Действие | Управление |
|---|---|
| Найти функцию | `Ctrl+K` |
| Обновить страницу | `F5` или кнопка обновления |
| Открыть / закрыть DevTools | `F12` |
| Закрыть вкладку | Средняя кнопка мыши (СКМ) или `×` |
| Переставить вкладки | Перетаскивание мышью |
| Прокрутить полосу вкладок | Колесо мыши |
| Отменить ввод адреса | `Esc` или клик вне строки |

## Пользовательские функции

В разделе «Дополнительные функции» доступны слоты для собственных скриптов. Принимаются файлы `.js`; всего можно загрузить до девяти функций. Загруженная функция получает свой переключатель и появляется в поиске `Ctrl+K`. Карточки можно менять местами перетаскиванием. Для удаления нажмите `⋯` на карточке.

## Сборка из исходников

Для сборки Windows EXE нужны Windows x64, Node.js 20+ и npm.

```powershell
npm ci
npm run build
```

Результат: `release/AnimeOn Desktop.exe`.
