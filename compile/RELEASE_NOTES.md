# AnimeOn Desktop v0.4.10 — Release Notes

В этом релизе представлено крупное обновление системы вкладок, добавлены пользовательские функции (.js), функция быстрой очистки кэша, расширенный журнал работы и множество улучшений удобства интерфейса!

---

### ✨ Главные новшества

* 🧩 **Пользовательские функции (.js)**:
  * В разделе «Функции» появился блок «Дополнительные функции» с поддержкой до 9 пользовательских JavaScript-скриптов.
  * Каждый скрипт получает свой тумблер включения/выключения, интеграцию в быстрый поиск через `Ctrl+K`, возможность изменения порядка перетаскиванием (drag-and-drop) и быстрое удаление через контекстное меню.
* 🗂️ **Улучшенная полоса вкладок**:
  * Поддержка до 7 одновременно открытых вкладок.
  * Отображение иконок сайтов, индикаторов воспроизведения звука и быстрого мьюта вкладки.
  * Контекстное меню для быстрого закрепления и управления звуком.
* 🧹 **Быстрая очистка кэша**:
  * В Настройках появилась кнопка мгновенной очистки кэшированных файлов и изображений Chromium без сброса авторизации и сохранённых профилей.
* 📋 **Расширенный журнал событий**:
  * Журнал теперь вмещает до 30 записей с точными временными метками и сохраняет стабильный размер без скачков интерфейса.
* 🏆 **Секретные достижения**:
  * Обновлен локальный список секреток.
* 🔍 **Поиск по `Ctrl+K`**:
  * Палитра команд теперь мгновенно ищет функции и пользовательские скрипты по названию и описанию.

---

### 🎨 Дизайн и интерфейс

* **Идеальное выравнивание и баланс колонок**:
  * Цветовая палитра и стили карточек профилей приведены в буквальное соответствие 1:1 с карточками адресов сайта.
  * Выровнены кнопки действий `⋯` и статусы профилей по единой горизонтальной оси.
  * Новый стильный тёмно-фиолетовый дизайн для предупреждений и ошибок ввода адреса.
* **Адресная строка**:
  * Визуально компактный адрес без `https://`, который автоматически сохраняет полный протокол `https://` при копировании в буфер обмена.

---

### 🛡️ Стабильность и оптимизация

* Отдельный каталог для логов (`%LOCALAPPDATA%\AnimeonDesktop\logs`) — основная папка данных теперь остаётся чистой.
* Оптимизировано энергопотребление и фоновая работа вкладок при свёрнутом окне.
* Повышена надёжность изоляции профилей и миграции сессионных данных при смене домена.
