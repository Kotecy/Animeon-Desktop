## ✨ Возможности

- 🗂️ **Вкладки сайта** — до 7 вкладок, иконки сайтов, закрепление, индикатор воспроизведения звука и быстрое отключение звука.
- 👥 **Мультипрофили** — до 4 изолированных сессий с мгновенным переключением и сохранением авторизации.
- 📡 **Детектор аномалий** — фоновое обнаружение аномалий с настраиваемым звуковым сигналом, тостами и счётчиком оставшихся попыток.
- 🤝 **Взаимная автоподписка** — автоматический ответ взаимностью новым фолловерам с поддержкой белого и чёрного списков.
- 🧩 **Пользовательские функции** — до 9 слотов для загрузки собственных JavaScript-скриптов (`.js`).
- 🏆 **Секреты** — каталог секретных достижений с отслеживанием прогресса и подсказками по получению.
- 🧹 **Очистка кэша** — быстрое освобождение дискового пространства в один клик без сброса авторизации и сохранённых профилей.
- 🔄 **Обновления** — встроенная проверка новых версий через GitHub Releases прямо из настроек.

## 📦 Установка

1. Скачайте **AnimeOn Desktop.exe** из [Releases](https://github.com/Kotecy/Animeon-Desktop/releases).
2. Запустите файл. Установка не требуется.
3. Войдите в AnimeOn и включите нужные функции.

Данные приложения находятся в `%LOCALAPPDATA%\AnimeonDesktop`.
Обновление не очищает их автоматически. Только при проблемах и по желанию можно закрыть приложение и удалить эту папку для чистого старта. **Это сбросит настройки и все входы в аккаунты.** Сохраните резервную копию, если хотите иметь возможность вернуть данные. Это полный сброс, а не очистка только кэша.

Google может отклонять вход во встроенном браузере. Клиент не гарантирует устранение этого ограничения; можно воспользоваться другим доступным на сайте способом входа.

<details>
<summary>🛠️ Сборка из исходников</summary>

Для сборки Windows EXE нужен Node.js 20+ и npm.

```cmd
cd compile
npm install
npm run build
```

Результат сборки будет сохранён в папке `release`.

</details>
